## English

Kiri now includes a lightweight video editor for cleaning up local recordings and saving an edited copy.

- Split recordings, remove unwanted sections, drag clips into a new order, and trim either edge. Each clip supports 0.25×–4× speed, with matching preview and export duration.
- The timeline shows the finished video without deleted gaps. Drag the divider to adjust its height; additional effect tracks scroll inside it instead of shrinking the preview. Editing supports undo and redo.
- Add timed drawing, shapes, arrows, text, and mosaic with the screenshot annotation tools. Privacy masks offer solid, blur, and pixel styles. Zoom effects include adjustable framing and animated transitions.
- Playback controls, speed selection, and export quality use clearer controls that remain readable over light and dark footage. Original recordings remain unchanged; edits save as a new library item.
- Processing stays local and uses platform media APIs. macOS clip speed preserves audio pitch; Windows speed changes also change audio pitch, as indicated in the editor.

Automated native media fixtures check reordered clips, mixed speeds, audio, and timed effects. Interaction checks cover dragging, undo/redo, continuous playback, multiple tracks, and narrow layouts. Windows checks run on hosted CI; these do not replace testing on every physical Windows or Intel Mac device. Installing the new build over an open, unsaved editing session requires saving or discarding that session first.

Version 1.4.9 and later can update through **Settings → About → Check for Updates**. Downloads include a Universal DMG for macOS 14+ on Apple silicon and Intel, and a Windows 11 x64 installer. macOS retains the existing local signing identity and is not Apple-notarized; first installation may require **Open Anyway** in Privacy & Security. Windows installers are not Authenticode-signed. Update downloads retain signature verification and separate user-controlled installation steps.

## 中文

Kiri 现在提供轻量视频剪辑，可整理本地录屏并另存编辑后的副本。

- 支持分割、删除多余片段、拖动调整顺序，以及拖动两端裁剪。每个片段可单独设置 0.25×–4× 速度，预览和导出的成品时长保持一致。
- 时间轴按成品排列，不再保留已删除片段的空隙。可拖动分隔线调整时间轴高度；增加效果轨道时在内部滚动，不再不断挤压预览。编辑支持撤销和重做。
- 截图中的画笔、图形、箭头、文字与马赛克工具可用于视频，并分别设置显示时段。隐私遮挡提供纯色、模糊和像素样式；局部放大支持取景调整和动画过渡。
- 播放控制、速度选择与导出画质使用更清晰的控件，在浅色和深色画面上都易于辨认。原录屏保持不变，编辑结果另存为素材库中的新视频。
- 处理始终在本地通过系统媒体接口完成。macOS 的片段变速保留音调；Windows 变速会同时改变音调，编辑器中有明确提示。

原生媒体自动测试覆盖片段换序、混合倍速、音频和定时效果；交互检查覆盖拖动、撤销重做、连续播放、多轨道及窄窗口。Windows 验证在远程 CI 中完成，不能替代所有实体 Windows 与 Intel Mac 设备上的测试。打开的剪辑若尚未保存，安装新版前需要先保存或放弃该编辑状态。

v1.4.9 及以后可通过“设置 → 关于 → 检查更新”升级。提供 macOS 14+ Apple 芯片与 Intel 共用的 Universal DMG，以及 Windows 11 x64 安装包。macOS 沿用现有本地签名，未经 Apple 公证；首次安装可能需要在“隐私与安全性”中点击“仍要打开”。Windows 安装包未做 Authenticode 签名。应用内更新保留下载签名校验和由用户分别操作的安装步骤。
